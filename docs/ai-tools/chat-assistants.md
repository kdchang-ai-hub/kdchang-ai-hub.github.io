# 對話助理怎麼選

## 結論先講

| 如果你… | 建議主力 |
| --- | --- |
| 不確定、想要最通用的選擇 | **ChatGPT** |
| 每天要讀長文件、寫長文章 | **Claude** |
| 重度使用 Gmail／Google 文件 | **Gemini** |
| 公司用 Microsoft 365 | **Copilot**（再搭一個上面的） |
| 主要是查資料、要來源 | **Perplexity**（搭配上面任一個） |

**三家都有免費版，新手階段完全夠用。** 先選一個用滿兩週，再決定要不要換。

---

## 三家的性格差異

### ChatGPT（OpenAI）

**像什麼：** 一個什麼都略懂、資源最多的萬用助理。

**強在哪：**
- 生態系最完整，功能更新最快
- 圖像生成、資料分析、語音對話等整合度高
- 網路上教學與範例最多，遇到問題最好找答案

**要注意：** 功能多也代表介面比較複雜，新手容易被選項淹沒。先只用最基本的對話框就好。

---

### Claude（Anthropic）

**像什麼：** 一個文筆好、讀得快、講話有條理的資深幕僚。

**強在哪：**
- 長文件處理能力突出，適合貼一整份報告請它分析
- 中文寫作的語感與結構清楚，潤稿、改寫品質穩定
- 回答傾向誠實標示不確定，幻覺相對克制

**要注意：** 生態外掛沒有 ChatGPT 多，某些多媒體功能較少。

---

### Gemini（Google）

**像什麼：** 已經住在你 Google 帳號裡的助理。

**強在哪：**
- 與 Gmail、Google 文件、試算表、雲端硬碟深度整合
- 搜尋能力自然，查最新資訊順手
- 能直接處理你雲端硬碟裡的檔案

**要注意：** 整合帶來便利也帶來權限問題，公司帳號使用前請先確認 IT 政策。

---

## 用「你的工作」來分流

### 每天大量寫信、寫文案

→ Claude 或 ChatGPT 都好。關鍵不在工具，在你有沒有建立自己的 [提示詞模板](../prompts/index.md)。

### 每天要讀報告、論文、合約

→ **Claude**。長文件的理解與摘要是它最明顯的優勢。
搭配 NotebookLM 建立知識庫效果更好。

### 工作內容大量需要查最新資料

→ **Perplexity** 當查資料入口，答案再丟給主力助理整理成你要的格式。

### 要做數據整理、表格運算

→ **ChatGPT 的資料分析功能**（能實際跑程式計算，比純文字推論準得多），或 Gemini 搭配試算表。

### 公司已經導入 Microsoft 365 或 Google Workspace

→ 先用公司提供的（Copilot 或 Gemini），因為資料合規已經處理好。
個人再另外準備一個主力助理做不涉及公司資料的事。

## 免費版夠用嗎？

大部分人的答案是：**一開始夠，用熟之後會不夠。**

免費版通常的限制：

- 較快、較強的模型有使用次數上限
- 進階功能（深度研究、檔案分析、圖像生成）額度較少
- 尖峰時段速度較慢

**建議：** 免費版用到你**每週被額度擋住兩次以上**，再考慮付費。
那時你也才知道自己真正需要哪些功能。

---

## 換一家之前，先確認不是提示詞的問題

很多人覺得「這個 AI 不好用」，換一家之後發現一樣。
在換工具前，先檢查：

1. 你有沒有給足夠的背景？
2. 你有沒有說清楚要什麼格式？
3. 你有沒有給它一個範例？
4. 你有沒有換成推理模型試試看？

四項都做了還是不行，再考慮換家。方法在 [提示詞庫](../prompts/index.md)。
