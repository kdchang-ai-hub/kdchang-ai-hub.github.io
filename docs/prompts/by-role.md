# 依職業分類的提示詞

每一則都可以直接複製。**括號內是你要換掉的地方。**

:::tip 使用方式
複製 → 換掉括號內容 → 貼進 AI → 覺得好用就存進自己的筆記。
不要每次重打，這是最浪費時間的事。
:::

---

## 行銷／社群

### 社群貼文（一次產出多個版本）

```text
你是熟悉台灣社群生態的行銷企劃。
請針對「（產品／活動）」寫 5 則 Facebook 貼文，每則風格不同：
1. 痛點開場  2. 故事開場  3. 數據開場  4. 提問互動  5. 幽默梗圖式

條件：
- 目標客群：（描述年齡、職業、在意什麼）
- 每則 150 字內，開頭前兩行要能單獨吸引人停下來
- 結尾各給一個明確的行動呼籲
- 不要用「小編」「敲碗」這類老派用法
```

### 廣告文案 A/B 測試

```text
請為「（產品）」寫 6 組廣告標題＋內文，分成三種訴求各兩組：
A. 解決痛點  B. 展示成果  C. 降低風險（保證、試用）

每組標註：訴求類型、預期打中的客群、最可能失敗的原因。
```

### 競品與市場分析（謹慎使用）

```text
我要分析「（產業）」的市場。請先問我 5 個你需要知道的問題，
我回答後再產出分析。

重要：所有具體數據請標註「需查證」，不要提供你不確定的數字。
```

## 人資／招募

### 職缺說明

```text
你是熟悉台灣就業市場的人資顧問。
請撰寫「（職稱）」的職缺說明。

公司背景：（規模、產業、文化）
工作內容：（條列）
必備條件：（條列）
我們的優勢／劣勢：（誠實寫）

格式：關於我們／你會做什麼／我們期待／加分項目／福利，500 字內。
限制：不要寫我沒提供的福利；不要用「熱血」「像家一樣」這類說法。
```

### 面試問題設計

```text
針對「（職稱）」，設計 8 個面試問題：
- 3 個行為面試題（過去經驗）
- 3 個情境題（假設狀況）
- 2 個價值觀題

每題附上：想考察什麼、好答案的特徵、警訊答案的特徵。
```

### 績效回饋草稿

```text
幫我把以下零散筆記，整理成一份結構化的績效回饋。

結構：具體事實 → 造成的影響 → 建議的調整 → 下一季目標

原則：
- 每個評價都要對應具體事件，不要抽象形容
- 避免人格化評論（例如「態度不佳」），改成行為描述
- 語氣坦誠但對事不對人

【我的筆記】（貼上）
```

## 行政／專案

### 會議記錄整理

```text
請把以下逐字稿整理成：
1.【結論】最多 5 點
2.【待辦】表格：事項｜負責人｜期限
3.【待確認】沒有結論的事項

只使用逐字稿內容，沒提到的填「未指定」。
【逐字稿】（貼上）
```

### 專案時程拆解

```text
專案：（描述目標與交付物）
期限：（日期）
人力：（幾人、什麼角色）

請拆解成工作項目，輸出表格：
| 階段 | 工作項目 | 負責角色 | 預估工時 | 相依項目 |

另外列出：3 個最可能延誤的環節，以及各自的預防做法。
```

### 公告與通知

```text
幫我寫一則內部公告。
事項：（說明）
對象：（全體／某部門）
你希望他們做什麼：（行動）
生效時間：（日期）

格式：主旨 + 三段（背景、變更內容、你要做什麼），200 字內，語氣中性清楚。
```

## 業務／客戶溝通

### 開發信

```text
幫我寫一封陌生開發信。
我方：（公司、產品、最相關的一個優勢）
對方：（公司、職稱、我猜測他的痛點）
我的目標：（約 15 分鐘線上會議）

要求：150 字內、第一句就講對他的價值、不要自我介紹三行、
結尾給兩個具體時段選項。請提供三種版本（直接／顧問式／案例式）。
```

### 難纏情境回覆

```text
情境：（描述客戶的抱怨或要求）
我的底線：（能讓步到哪裡）
我想維持的關係：（長期客戶／一次性）

請提供三種回覆版本（強硬／中性／柔軟），
並各自說明：可能的後續發展、適合什麼情況使用。
```

### 提案摘要

```text
把以下冗長的提案內容，濃縮成客戶主管 60 秒能讀完的版本。

結構：他的問題 → 我們的解法 → 預期效益（含衡量方式）→ 下一步
限制：不要用專業術語；效益不要寫我沒提供的數字。

【原始提案】（貼上）
```

## 教師／培訓

### 課程大綱

```text
主題：（課程名稱）
對象：（年級／背景／人數）
時間：（幾堂課、每堂幾分鐘）
學習目標：（學完要會什麼）

請設計課程大綱，每堂課包含：
引起動機（5 分）｜核心概念｜實作活動｜檢核方式
並標出最容易讓學生卡住的地方與因應做法。
```

### 出題與評量

```text
針對「（主題）」，出 10 題（（題型））。
難度分佈：簡單 3、中等 5、困難 2。
每題附：答案、解析、這題想檢測的能力、學生最常選錯的選項與原因。
```

### 個別化回饋

```text
幫我把以下批改重點，寫成給學生的回饋。
原則：先肯定具體做得好的地方 → 指出一個最關鍵的改進點 →
給一個可執行的練習建議。語氣鼓勵但不空洞，150 字內。

【批改重點】（貼上）
```

## 學生／求職者

### 讀不懂的教材

```text
我是（科系／年級）的學生，正在讀「（主題）」但看不懂。
請：
1. 用一個生活比喻解釋核心概念
2. 拆成 5 個我該依序理解的小概念
3. 針對第一個小概念出 3 題自我檢測
4. 指出初學者最常見的兩個誤解
```

### 履歷優化

```text
以下是我的履歷片段。請幫我改寫成 STAR 結構（情境-任務-行動-結果），
並把每一項的成果盡量量化。

重要：如果我提供的內容沒有數字，請標註「（可補充數據）」，
不要幫我編造任何成果。

目標職缺：（貼上職缺說明）
【我的履歷】（貼上）
```

### 面試準備

```text
我要面試「（職稱）」，公司是（描述）。
請扮演該公司的面試官，一次問我一題，等我回答後再給回饋。

回饋請包含：這個回答的強項、最弱的一點、以及一個更好的答法範例。
準備 8 題，由淺入深。
```

## 生活與個人

### 規劃與決策

```text
我在考慮「（決定）」。
請先問我 5 個關鍵問題，我回答後，幫我整理成：
支持的理由｜反對的理由｜我可能忽略的風險｜三個可行方案的取捨
不要幫我做決定，幫我把選項看清楚。
```

### 把雜亂想法整理成行動

```text
以下是我腦中一團亂的想法。請幫我整理成：
1. 這些想法其實在講幾件事
2. 每件事的核心問題是什麼
3. 每件事的下一步具體行動（要能在 30 分鐘內開始的）

【我的想法】（貼上）
```

- AI 產出永遠是草稿，署名的是你，所以查證與潤飾也是你的工作
