# 提示詞庫

同樣一個問題，為什麼別人問得到好答案，你卻得到一堆廢話？
差別幾乎都在**你有沒有把話講完整**。

這一章給你可以直接複製的模板，以及把模板改成你自己版本的方法。

---

## 核心公式：角色 × 任務 × 脈絡 × 格式

90% 的提示詞問題，用這四段就能解決：

```text
【角色】你是一位有 10 年經驗的 ____。
【任務】請幫我 ____。
【脈絡】背景是 ____。對象是 ____。我的目標是 ____。已知條件有 ____。
【格式】請用 ____ 呈現，長度約 ____，語氣 ____。
```

### 對照範例

**不好的問法**

```text
幫我寫一封請假信
```

**好的問法**

```text
【角色】你是熟悉台灣職場書信禮儀的資深行政人員。
【任務】幫我寫一封請假申請信給我的直屬主管。
【脈絡】我是行銷部專員，要請 3 天特休（10/14–10/16）出國。
手上的社群媒體排程已經做完到月底，緊急事項由同事小林代理。
我跟主管關係還不錯，但信件仍需保持專業。
【格式】200 字以內、正式但不生硬、主旨另外列出、結尾附上交接說明。
```

差別不在 AI 變聰明了，而是你把它需要的資訊給齊了。

## 讓答案再好一階的五個技巧

### 1. 給一個範例（最有效）

```text
請依照以下範例的風格與結構，幫我寫三則新的：

【範例】
標題：三分鐘搞懂勞退新制
開頭：你每個月薪資單上那個 6%，其實不是政府給的。
結構：懸念開頭 → 三個重點 → 一句行動呼籲

【我的主題】
（寫下你的主題）
```

一個好範例，勝過十句形容詞。

### 2. 要求它先問你問題

```text
在開始之前，請先問我 3~5 個你需要知道的問題，
等我回答完再產出。不要自己假設。
```

這招能避免它憑空腦補，尤其適合複雜任務。

### 3. 要求分步驟、先給大綱

```text
請先給我大綱，我確認後再寫內文。
```

避免它一次寫完三千字，結果方向根本是錯的。

### 4. 指定「不要什麼」

```text
請避免：空泛的形容詞、「在當今快速變化的時代」這類開場、
條列超過 5 點、使用我沒提供的數據。
```

### 5. 讓它自我檢查

```text
寫完後，請用以下標準檢查一次並修正：
1. 有沒有我沒提供卻被你補上的資訊？
2. 有沒有超過 200 字？
3. 主管讀完知道要做什麼嗎？
```

## 常用情境模板

### 整理會議記錄

```text
以下是一份會議逐字稿。請幫我整理成：
1.【結論】最多 5 點，每點一句話
2.【待辦】表格：事項｜負責人｜期限
3.【待確認】會中沒有結論、需要後續釐清的事項

規則：只使用逐字稿中的內容，不要補充。
逐字稿中沒提到負責人或期限的，請填「未指定」。

【逐字稿】
（貼上）
```

### 寫一封難寫的信

```text
幫我寫一封信，並提供三種語氣版本（強硬／中性／柔軟），
讓我挑一種再請你細修。

情境：（描述背景、雙方關係、你的目標、你的底線）
收件人：（職稱與關係）
長度：200 字以內
```

### 讀懂一份長文件

```text
請閱讀以下文件，然後：
1. 用 5 句話說明它在講什麼
2. 列出對「（你的角色／你的目的）」最重要的 3 個重點
3. 列出文件中我可能會忽略但很關鍵的細節
4. 列出文件中沒有說清楚、我應該追問的問題

【文件】
（貼上）
```

### 腦力激盪

```text
請針對「（主題）」發想 15 個點子，要求：
- 前 5 個走安全保守路線
- 中間 5 個走「別人可能沒想到」的角度
- 最後 5 個刻意誇張、不考慮可行性

每個點子一句話說明，不要解釋太多。
```

### 學一個新東西

```text
我想學「（主題）」，我目前的程度是（描述）。
請：
1. 用一個生活比喻解釋核心概念
2. 列出我應該依序理解的 5 個子主題
3. 針對第一個子主題，出 3 題讓我自我檢測
4. 指出初學者最常見的 2 個誤解
```
