# 學習資源總覽

歡迎來到 **KD AI Hub**。這裡把 AI 學習拆成八個主題，每一個主題都假設你沒有技術背景，
用一般人的語言重新寫過，而且每篇都要能回答「所以我現在該做什麼」。

:::tip 第一次來？
不用從頭讀。先花 20 分鐘做完 [新手起步](/start)，再看 [學習地圖](/roadmap) 決定接下來的方向，
效率會比一頁一頁翻高很多。
:::

## 八大主題

### [AI 基礎觀念](./ai-basics/index.md)

搞懂大型語言模型在做什麼、為什麼會說錯話、Token 與上下文是什麼意思。
不碰數學、不碰程式，只用你聽得懂的比喻。

### [AI 工具圖鑑](./ai-tools/index.md)

對話助理、寫作、簡報、圖像、影音、研究、翻譯——每一類幫你挑好 2~3 個夠用的工具，
直接告訴你誰適合你、免費版能做到哪裡。

### [提示詞庫](./prompts/index.md)

可以直接複製使用的 Prompt 模板，依職業與情境分類，每一則都附上「怎麼改成你的版本」。

### [職場與生活應用](./use-cases/index.md)

行銷、人資、行政、業務、老師、學生、家長、自由工作者——每個角色一份今天就能用上的清單。

### [工作流與自動化](./workflows/index.md)

從一次問一個問題，進化成一整套會自己跑的流程。知識庫、Agent、自動化工具的入門說明。

### [Vibe Coding 入門](./vibe-coding/index.md)

不會寫程式也能做出小工具。用自然語言描述需求，讓 AI 幫你把東西做出來。

### [安全與判斷力](./safety/index.md)

哪些資料不能貼進 AI？怎麼查證答案？公司內部使用要注意什麼？先學會保護自己，才能用得久。

### [名詞速查表](./glossary.md)

看到看不懂的詞，來這裡查。每個詞條都有一句話解釋加一個生活比喻。

## 使用本站的四個建議

1. **從真實任務開始** — 挑一件你這週本來就要做的事，用 AI 做做看，學習才會留下來。
2. **一次只換一個變數** — 換工具、換模型、換問法，一次只動一項，才知道是哪一步有效。
3. **把有效的問法存起來** — 問到好答案時立刻存進筆記，三個月後這份筆記比任何教學都有用。
4. **永遠保留最後判斷** — AI 負責草稿與速度，你負責事實與責任。
